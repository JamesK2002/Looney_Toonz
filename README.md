# Looney_Toonz
Final Project CSCI 310

Looney Toonz characters: 
- Bugs Bunny
- Tweety Bird
- Marvin Martian: Can eliminate competitors if they step on the same square, can take their flag. 
- Tazmanian Devil

Objective:
- Claim new "Planet X"
- Obtain a carrot flag
- Win condition: Bring it to the top of the mountain
- Two flags
- One mountain
- Marvin changes the mountains position (randomly?) every 3 complete cycles
- Cannot climb mountain without the flag

Methods:
- Motion: move one square per round
- Movement is random
- (most important, key point) Each character is a thread, use multi-Threading
- Representation is up to us, example in slide but not required to follow
- Any coding language
- Make sure to represent which character and who has the flag
